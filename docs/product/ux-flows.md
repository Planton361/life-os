# UX Flows

Stand: 2026-06-17  
Status: Active  
Zweck: Hauptflüsse der App.  
Quelle der Wahrheit: `PRODUCT.md`.  
Gilt für: UX-Design und Feature-Priorisierung.  
Nicht gilt für: technische Implementierungsdetails.

## Quick Capture

```text
Open Quick Thought / Command
→ choose type
→ enter content
→ optional area/project/date
→ save to Inbox or target entity
```

## Inbox Processing

```text
Open Inbox
→ select item
→ decide: task / note / project / archive
→ add next step
→ link area/project
→ mark processed
```

## Daily Planning

```text
Open Dashboard
→ check Daily Control
→ scan Today Agenda
→ clear urgent Inbox
→ start focus block
```

## Daily Review

```text
Open Review
→ log outcome
→ note wins
→ close open loops
→ move unfinished items
→ set tomorrow hint
```

## Weekly Review

```text
Open Week / Review
→ review tasks/projects/goals/habits
→ identify blockers
→ set next week focus
```
