# 0001 – App First

Stand: 2026-06-17  
Status: Accepted

## Kontext

Life OS begann mit Notion-orientierten Strukturen. Das Ziel ist nun eine eigene Web-App.

## Entscheidung

Life OS wird app-first gebaut. Notion bleibt nur methodische Inspiration.

## Konsequenzen

- echte Routen, Formulare, Command Palette und Visualisierungen sind erlaubt
- Auth, Privacy und RLS werden Pflicht
- Dashboard ist App-Cockpit, keine Notion-Datenbankseite
- alte Notion-Regeln werden archiviert, nicht aktiv gehalten
