# 0005 – Codex Capability Layer

Status: Accepted

## Entscheidung

Life OS integriert vor Phase 2 eine kontrollierte Codex Capability Layer.

## Begründung

Codex soll V5, Produktlogik, Designsystem und Sicherheitsregeln nicht jedes Mal neu per Prompt erhalten. Skills und MCPs werden kontrolliert genutzt, um Wiederholbarkeit und Qualität zu erhöhen.

## Enthalten

- `.agents/skills/life-os-design-taste`
- `.agents/skills/life-os-codex-task-writer`
- Context7 als erstes MCP
- Superpowers als optionale Plan-/Spec-/TDD-Methodik
- UI UX Pro Max als Design-Review-Hilfe, nicht Designquelle

## Nicht enthalten

- autonome Agenten
- automatische externe Tool-Ausführung
- fremde Skills ohne Review
- Produktfeatures
- neue Designrichtung

## Konsequenzen

Phase 2 startet erst nach diesem Enablement.
