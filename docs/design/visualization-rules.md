# Visualization Rules

Stand: 2026-06-17  
Status: Active  
Zweck: Regeln für Progress, Charts, Dots und Motivation.  
Quelle der Wahrheit: `DESIGN.md`.  
Gilt für: Dashboard und Area Dashboards.  
Nicht gilt für: komplexe Analytics-Seiten späterer Phasen.

## Grundregel

```text
Visualisierung muss eine Entscheidung erleichtern oder Verhalten verstärken.
```

## Dashboard-Regeln

- P0/P1-Visuals dürfen sofort sichtbar sein.
- P2/P3-Visuals bleiben leise.
- Maximal wenige dominierende Progress-Elemente im ersten Blick.
- Jede Visualisierung hat Titel oder Textaussage.
- Keine Farbcodierung ohne Label.

## Muster

- Progress Bar: Projects, Goals, Skills, Week.
- Dots: Habits, Training, Review-Streak.
- Sparkline: Mood, Energy, Learning Time.
- Timeline: Today, Week, Deadlines.
- Compact Metric: Weight, Calories, Sleep.

## Nicht verwenden

- 3D-Charts
- Donut-Flut
- große Analytics im Main Dashboard
- reine Dekorationscharts
- GitHub-Heatmap als Hauptwidget
