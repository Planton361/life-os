# Figma Handoff

Stand: 2026-06-17  
Status: Active  
Zweck: Übergabe der finalen V5-Figma-Richtung in Code.  
Quelle der Wahrheit: Figma-Datei `Dashboard Overhaul V5 – Subtle Color Identity Polish`.  
Gilt für: manuelle Umsetzung, Screenshot-Vergleich, Codex-Prompts.  
Nicht gilt für: automatischen Import von Figma in Code ohne Review.

## Handoff-Regeln

- Figma ist Designreferenz, nicht automatisch perfekte Code-Struktur.
- Komponentengrenzen in Code nach Produktlogik schneiden.
- Spacing, Farben und Hierarchie zuerst übernehmen.
- Copy/Microcopy darf bei Bedarf produktlogisch geschärft werden.
- Responsive Verhalten explizit definieren, nicht aus WQHD erraten.

## Prüfschritte

1. Screenshot Code vs. Figma auf WQHD vergleichen.
2. P0/P1-Hierarchie prüfen.
3. Card-Dichte prüfen.
4. Dark-UI-Kontrast prüfen.
5. Mobile-Reihenfolge prüfen.
6. Keine alten Dashboard-Varianten einmischen.
