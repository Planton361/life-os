## Kurzfassung

V5 ist ein dunkles, ruhiges, präzises WQHD-Command-Center. Es ist informationsreich, aber nicht laut. Die Steuerung entsteht durch P0–P3-Hierarchie, Zonenlogik, klare Card-Typen und semantische Farbe.

## Zonen

| Zone | Zweck | Priorität |
|---|---|---|
| Sidebar | Navigation, Areas, Inbox-Hinweise | P1 |
| Command Center | Tagesstatus, globale Steuerung | P1 |
| Quick Thought | schnelle Erfassung | P1 |
| Daily Control | aktueller Task, nächste Warteschlange | P0 |
| Today Agenda | zentraler Tagesplan | P0 |
| Mood Check | Zustand kurz einordnen | P1 |
| Habit Tracker | Routinenstatus | P1 |
| Active Portfolio | aktive Projekte/Ziele/Skills | P1 |
| Health/Nutrition Stack | Gewicht, Makros, Meals, Running | P2 |
| Time Progress | Zeitkontext | P3 |
| Anti-Rot Actions | Bad-Habit Reset | P3 |
| Challenges | kleine Verhaltenstrigger | P3 |

## Layoutregeln

- Today Agenda bleibt zentraler Anker.
- Daily Control steht visuell in unmittelbarer Nähe zur Top-Steuerung.
- Rechte Spalte unterstützt, ersetzt aber nicht Today.
- Linke Health/Nutrition Cards bleiben kompakt.
- Bottom Row ist unterstützend, nicht Hauptfokus.

## Reviewfragen

- Ist der nächste Schritt sofort erkennbar?
- Ist Today visuell stärker als P2/P3?
- Werden Farben durch Text gestützt?
- Ist die Dichte hoch, aber scanbar?
- Gibt es keine überflüssige Dekoration?
