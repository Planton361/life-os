# COMPONENT_RULES.md

Stand: 2026-06-12

## Zweck

Standardkomponenten für die Life OS App.

## AppShell

- Sidebar, Topbar, Main, optional ContextPanel.
- Desktop klar strukturiert.
- Mobile mit Bottom/Drawer Navigation.

## DashboardHero

- ein Hauptfokus.
- max. 3 Meta-Items.
- keine langen Zitate.
- optional Progress/Status.

## QuickActions

Maximal 6.

- + Gedanke
- + Aufgabe
- + Tageslog
- + Training
- + Lernlog
- + Agent Session

## DashboardCard

- eine Aufgabe pro Card.
- 3–7 Items.
- Header mit Zweck.
- Count optional.
- Footer Link optional.

## CompactList

- Haupttext zuerst.
- Meta sekundär.
- max. 4 Meta-Infos.
- keine Tabellenwand.

## Pill

- Status, Area, Priority, Duration.
- klein, textlich verständlich.
- Farbe nur ergänzend.

## ProgressBar

- Projekte, Ziele, Habits, Skills.
- immer mit Textwert.
- nicht für alles.

## WeekDots

- Habits, Review, Training.
- 7 Punkte.
- Status textlich ergänzen.

## Sparkline

- Trends.
- keine Detailanalyse.
- nur auf Detailseiten oder kleine Snapshot Cards.

## EmptyState

- erklärt, was fehlt.
- bietet nächste Aktion.
- kein generischer Platzhalter.

## ReviewFlow

- DailyReview
- WeeklyReview
- offene Loops
- Wins
- nächster Fokus

## CommandPalette

- Navigation
- Quick Add
- Suche
- Shortcuts
- nicht überladen.
