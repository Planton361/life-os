# Supabase Workspace

This directory is prepared for future local Supabase migrations.

- `supabase/.temp/` and `supabase/.branches/` are local-only CLI artifacts.
- Future schema migrations belong in `supabase/migrations/`.
- Do not commit secrets, tokens, local credentials, database dumps, or generated caches.
- Do not link or push to a remote Supabase project without explicit approval.
